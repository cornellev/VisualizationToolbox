# Cross-Team Analysis Toolbox

## Team Members
Ajay Parthibha, Amelia Zheng, Rhea Agrawal

## Summary
Visualization tool consisting of Dynamic and Static Analysis for Mechanical, Electrical, and Autonomy subteams. Dynamic Analysis is used for Pointcloud visualization and Static Analysis involves graphical displays, such as visualizing run data. This project is dockerized, so it can be hosted locally on the computer in the ELL.
